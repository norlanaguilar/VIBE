# Carpeta de Música VibeLocal

Coloca tus archivos de música en esta carpeta desde la app **Archivos** (iOS) o tu explorador de archivos (Android).

### Formatos soportados:
- MP3 (`.mp3`)
- M4A / AAC (`.m4a`, `.aac`)
- WAV (`.wav`)
- FLAC (`.flac`)

La aplicación **VibeLocal** identificará automáticamente cada canción con su carátula e información de artista mediante IA.
